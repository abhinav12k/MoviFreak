# MoviFreak
Una simple aplicación para Android que ayuda a los usuarios a descubrir películas y series. Se puede usar para ver reseñas y tráilers de las últimas películas o series mejor calificadas. Es el hogar ideal para los amantes del cine y la televisión. Obtén todo lo que necesitas saber sobre una película o serie.

# Características:
* Descubre el catálogo de las películas y series más populares y mejor calificadas
* Mira los últimos tráilers y adelantos de películas o series
* Lee reseñas de otros usuarios
* Material Design
* Modo Día/Noche
* Marca películas o series como favoritas
* No es necesario salir de la aplicación para ver tráilers y adelantos (Reproducción de video en la aplicación)
* Guarda películas o series para su uso sin conexión

## Construido con 🛠
- [Kotlin](https://kotlinlang.org/) - Lenguaje de programación de primera clase y oficial para el desarrollo de Android.
- Java
- [Componentes de Arquitectura de Android](https://developer.android.com/topic/libraries/architecture) - Colección de bibliotecas que te ayudan a diseñar aplicaciones robustas, probables y mantenibles.
  - [LiveData](https://developer.android.com/topic/libraries/architecture/livedata) - Objetos de datos que notifican a las vistas cuando la base de datos subyacente cambia.
  - [ViewModel](https://developer.android.com/topic/libraries/architecture/viewmodel) - Almacena datos relacionados con la interfaz de usuario y captura cambios en la interfaz. 
  - [Room](https://developer.android.com/topic/libraries/architecture/room) - Biblioteca de mapeo de objetos SQLite.
- [Componentes de Material para Android](https://github.com/material-components/material-components-android) - Componentes de interfaz de usuario de Material Design para Android
- [MoviesDb](https://www.themoviedb.org/documentation/api) - API para obtener películas/series
